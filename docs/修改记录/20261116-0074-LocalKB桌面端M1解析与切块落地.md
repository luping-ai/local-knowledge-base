## 3. 六个真实缺陷（都是自己写错、被测试或实测抓到的）

### 3.1 `_best_cut` 越界 → 产出完全相同的块

`limit` 超过字符串长度时返回了 `len(s)+1`，调用方 `s[:cut]` 拿到全文、`rest = s[cut:]` 为空，循环原地踏步。

**症状**：`_split_long('字'*3000)` 返回两个 600 字的相同块。

**修复**：`limit = min(limit, len(s))`。

### 3.2 `Block` 没有 `page_end` → 跨页段落页码永远是 0

`pdf.py` 里写了 `blocks[-1].page_end = p.page`。`Block` 是普通 dataclass，**允许动态加属性**，所以这行不报错、但也不生效。

**症状**：跨页段落的结束页码永远是 0，来源卡片显示的页码比实际内容少一页。

**修复**：`Block` 增加 `page_end` 字段与 `page_span` 属性。

### 3.3 页眉页脚判定误伤单行页面

6 页、每页一行的 PDF：那一行 y 坐标在顶部 8% 区域内，归一化后各页"重复"（数字变 `#`）→ 被判为页眉全部丢弃 → 报"几乎没有可提取的文字"。

**修复**：加第 4 条判据——**该页必须还有其他内容**。真页眉一定与正文共存；一页只有一行时，那一行就是正文。

### 3.4 不同 sheet / 章节被合并成一块

`flush_group()` 在标题切换时被调用，但它内部读的是**当前** `heading_stack`——而栈已经压入了新标题。于是上一个 sheet 的数据被打上新 sheet 的名字。

**症状**：两个 sheet 各一行的小文件被切成 1 块，`heading_path` 只有最后那个。

**修复**：`flush_group(path)` 接受路径参数，由调用方在压栈**之前**传入旧路径。

### 3.5 跨页聚拢丢失页码精度

三页、每页一行的 PDF 被切成 1 块（`page_start=1`、`page_end=3`）。用户点"跳到第 3 页"看到的内容与引用片段对不上——而"能跳回原文"是产品的核心承诺。

**修复**：两条规则——`_pack` 里跨页不聚拢；`_merge_short_tail` 里跨页不合并。

**顺带修正了两条错误的旧测试**：它们原本断言"合并后 page_end 更新为 5"，那是把跨页合并当成了正确行为。

### 3.6 只有标题的文档切出 0 块

内容为 `# a` 的 md：标题被暂存到 `pending_heading` 等待正文，而正文永远不来 → 0 块 → 报"解析成功但切不出任何块" → 标为失败 → **下次扫描反复重试、永远好不了**。

**修复**：循环结束后若 `pending_heading` 仍在，单独成一个 `heading` 类型的块。

### 3.7 扫描结果根本没落库（M0 遗留）

`local_files` 一直是空的。后果不只是"下次重新解析"：

- 每次显示"新增 95 篇"，看起来像在重复导入
- `missing` 检测失效（没有旧行可查）
- 完全重复分组（§12.3）没有数据源

**修复**：`parse_all` 末尾 `_persist()`。状态定为 `pending` 而不是 `imported`——M1 还没真正提交给 Runtime，写 `imported` 会让下次 diff 认为"已在库里"，一篇从未入库的文档被永久跳过。

### 3.8 异常兜底把代码错误伪装成"文件损坏"

`registry.parse` 的 `except Exception` 把 `SyntaxError` 也包成了"无法解析这个文件（格式异常或内容损坏）"。

**实际后果**：`pdf.py` 里一个引号嵌套错误被这条兜底吞掉，报错信息变成"这个 PDF 损坏了"——排查方向完全错误。

**修复**：`SyntaxError` / `ImportError` / `AttributeError` / `NameError` / `TypeError` 放行。它们是代码/环境问题，不是文件问题。

### 3.9 python-docx 抛的不是 `BadZipFile`

只捕 `zipfile.BadZipFile` 时，损坏的 `.docx` 落到"无法打开这个 Word 文档"——指向不明。python-docx 抛的是自定义的 `PackageNotFoundError`（继承 `Exception`）。

**修复**：按消息判断（`package not found` / `not a zip`），给出"文件已损坏"这个可行动的结论。

## 5. 与方案文档的两处偏差

| 方案原写 | 实际实现 | 原因 |
| --- | --- | --- |
| 未提"跨页不聚拢" | 增加该规则 | 页码是溯源坐标，跨页聚拢会让"跳到第 N 页"失真 |
| 未提"只有标题的文档" | 标题单独成块 | 否则切出 0 块 → 标失败 → 永久重试 |
