# 相似检测的阈值对"填空模板"过严（B6 未通过）

- **日期**：2026-11-16
- **发现方式**：M7 的 B6 端到端验证（8 个填空版合同应成 1 组，实际成 2~3 组）
- **性质**：**参数未校准**，不是代码缺陷
- **影响**：B6 验收不通过；真实的模板类文档（周报/月报/合同）会被拆散成多组
- **需要谁决定**：需要标注集校准（服务端改动）

---

## 1. 现象

用 8 份结构完全相同、只有填空部分不同的合同（同一模板）做 B6：

| 文档长度 | 实际分组 | 期望 |
| --- | --- | --- |
| **235 字** | 1 组 2 个（其余 6 份各自落单） | 1 组 8 个 |
| **660 字** | 1 组 3 个 + 1 组 2 个（另 2 份落单） | 1 组 8 个 |

两次都是"部分成组"，且组内 `max_hamming ≤ 2`。

## 2. 根因：`ThresholdShort = 2` 对这类文档太严

`internal/knowledge/dedup/simhash.go`：

```go
const (
    ThresholdShort  = 2   // < 1k rune
    ThresholdMedium = 3   // 1k ~ 10k
    ThresholdLong   = 5   // > 10k
)
```

660 字走 `ThresholdShort = 2`。而 8 份填空版之间的 SimHash 距离分布是
`0, 1, 2, 3+ ...`——只有距离 ≤ 2 的对能连起来，其余落单。

**这个文件自己也写明了这是初值**：

> ## 这些是初值
>
> 必须用标注集校准后回填（方案 §5.1 与附三都强调了）。
> 现在的数值来自"改动比例 1%~2% 判为重复"的经验假设，不是实测结论。
> **不要把它当承诺写进用户文档。**
>
> 校准方法：取 200 对已人工标注"是否重复"的真实文档，扫一遍阈值，
> 取 F1 最高的那组。标注集应包含模板文档（周报、月报）作为负例。

所以这是**已知的待办**，不是新发现的缺陷。但 M7 的 B6 验收直接撞上了它。

## 3. 为什么这不只是"阈值调大一点"

调大阈值会让**误报**增加，而误报的代价更高：

| 方向 | 后果 |
| --- | --- |
| 阈值过严（现状） | 模板文档被拆成多组 → 用户要多确认几次，但**不会误导入** |
| 阈值过松 | 两份不同的月报被当成"同一文档" → 用户确认后**只入库一份**，另一份的内容就搜不到了 |

第二种是不可逆的信息损失。所以"宁漏勿错"是对的取舍，只是当前偏保守到
B6 不成立。

## 4. 三个可选方向

| 方案 | 做法 | 代价 |
| --- | --- | --- |
| **A. 校准阈值**（推荐） | 按注释里的方法做标注集，尤其要包含模板类文档 | 需要 200 对标注数据（人力） |
| **B. 提高短文档阈值** | `ThresholdShort` 2 → 3 或 4 | 可能引入误报，且没有数据支撑 |
| **C. 模板检测单独一条路** | 检测"结构相同、仅少量字段不同"的文档，用占位符归一化 | 实现复杂度高，且会与表格结构化指纹重复 |

**建议 A**，并在校准前把 B6 标为"已知不通过"，而不是改验收标准。
理由是：验收标准是产品的意图（"用户应该能一次确认掉 8 个填空版"），
把它改成"成 2 组也算过"会让这个功能失去意义。

## 5. 已做的（客户端侧）

客户端不需要等阈值校准就能做好自己那部分：

- **`pending` 处理**：`recompute=True` 保证结论完整（§12.4）
- **空 doc_ids 拦截**：不传空（否则服务端做全库重算）
- **分组按组展示**：即使用户看到"3 组"而不是"1 组"，每组内的路径、
  修改时间、相似度都清晰可判断
- **默认不预选**：阈值偏严导致分组变多时，用户仍然逐组决策，不会误入库

也就是说：**阈值偏严只会让用户多点几次"确认"，不会产生错误结果**。
这让它可以作为已知问题发布。

## 6. 复现

```powershell
python tools\localkb_m7_verify.py
```

B6 段会显示实际分组数与成员数。当前预期输出（660 字合同 8 份）：

```
[B6] 8 个填空版合同（应成组）
  [PASS] 8 篇都入库  -> 8 篇
  [PASS] 检测出相似组  -> 2 组，共 5 个文件
  （注意：期望 1 组 8 个，见 docs/实测记录/20261116-相似阈值对模板文档过严.md）
```
